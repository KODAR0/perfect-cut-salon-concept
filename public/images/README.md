# Image replacement guide

All current salon photographs are temporary editorial placeholders. Replace files in the matching folders and update `src/data/business.ts`; components do not need to change.

- `hero/`: main landing image
- `interior/`: salon space and process images
- `services/`: service category images
- `staff/`: verified team portraits only
- `gallery/`: finished work and detail images
- `logo/`: verified owner-provided logo files only
